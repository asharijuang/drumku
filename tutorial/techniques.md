# Teknik Spesifik Drum

1. **Single Stroke** (N K N K): Kecepatan dan kelenturan dasar
2. **Double Stroke** (N N K K): Kontrol pantulan stik (rebound)
3. **Paradiddle** (N K N N - K N K K): Transisi arah tangan mulus
4. **Flam & Herta**: Variasi aksen sebagai bumbu utama
5. **Hand-Foot Coordination**: Integrasi Bass Drum dengan tangan
6. **Pola Linear**: N K K, N K N K, N K K N K K
7. **Orchestration**: Distribusi ke tom-tom dan cymbal
8. **Chops Populer**: Pola 16th Notes dan Triplet/Sextuplet
